# Icaro Launcher 0.2.2

Hotfix sobre 0.2.1 en la rama de mantenimiento `v0.2.x`, centrado en la actualización de Windows, la sincronización y la importación. Esta preparación local todavía no distribuye una actualización: requiere compilar y publicar los artefactos y su manifiesto en GitHub.

## Corregido

- La actualización mantiene bloqueadas las acciones incompatibles hasta cerrar el launcher y evita ayudantes simultáneos sobre el mismo ejecutable. Normaliza las rutas de Windows para PowerShell e Inno Setup, verifica la versión instalada y muestra el motivo del error.
- Reintentar una instalación puede reutilizar el paquete completo descargado, tras verificar tamaño y SHA-256. Los archivos parciales o alterados se descartan. Volver a consultar después de un fallo no inicia otra instalación automáticamente.
- La sincronización reconoce versiones anteriores y duplicadas por el ID interno y los hashes, incluso con nombres diferentes o la misma versión declarada. Retira las copias activas sustituidas, conserva un respaldo verificado y comprueba que no queden duplicados del mod requerido. Conserva los otros mods personales y los archivos desactivados.
- Una colisión desconocida con un JAR propio permite revisar el plan; reemplazarlo exige autorización y conserva una copia fuera de `mods`.
- El resumen de importación reparte el espacio entre etiquetas y valores para evitar texto cortado con listas largas de carpetas. Conserva iconos, imágenes y temas.

## Añadido

- **Instancia → Mods → Importar .jar** permite seleccionar varios archivos propios. Valida los JAR y sus límites, protege nombres ocupados y publica el lote de forma atómica. No descarga dependencias ni certifica la compatibilidad del contenido importado.

## Validación y límites

- Pruebas del núcleo, la interfaz y las regresiones de recuperación, integridad, conservación de archivos y duplicados de Apogee.
- Pruebas de PowerShell para reemplazo portable, reintento y ayudantes simultáneos; prueba del flujo de instalación con un instalador simulado. La actualización completa en el equipo afectado sigue pendiente de validación y de sus registros de error.
- Revisión visual del resumen y la lista de mods en Tinta y Piedra, con tamaños de ventana diferentes. Se verificó el plan contra el servidor real, sin aplicar cambios a la instancia desde esa comprobación; la reconexión al juego queda por confirmar.
- Se incluye una [investigación de rendimiento](../investigaciones/rendimiento-sincronizacion-2026-10-15.md), sus datos y un banco de pruebas reproducible. Las optimizaciones propuestas de caché, transacciones incrementales, concurrencia y presupuesto de API siguen pendientes; no se anuncia una mejora global de velocidad ya implementada.
