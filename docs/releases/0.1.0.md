# Icaro Launcher 0.1.0

Primera versión pública de Ícaro para Windows 10/11 de 64 bits. El proyecto sigue en desarrollo; esta entrega reúne los recorridos disponibles en el launcher y conserva la interfaz del System Design original.

## Descargar

- **Instalador (`-setup.exe`):** instala por usuario, crea los accesos y registra el enlace de inicio de sesión de Ícaro. Las actualizaciones posteriores se aplican en segundo plano desde el launcher, con un breve reinicio y regreso a Actualización.
- **Portable (`-portable.zip`):** incluye launcher, servicio del anfitrión y licencias. Extrae el ZIP completo antes de abrir `IcaroLauncher.exe`.
- **Ejecutable (`.exe`):** launcher individual, también utilizado por el actualizador portable.

El instalador y el portable conservan las instancias y ajustes en `%APPDATA%\Icaro`. Los paquetes incluyen hashes SHA-256 en `-artefactos.json` y los metadatos del actualizador en `latest.json`.

## Disponible

- Inicio de sesión con Microsoft, comprobación de Minecraft Java y sesión recordada. En Windows, el navegador vuelve por `icaro://oauth/microsoft`; no necesita una variable de prueba ni una página de localhost.
- Creación, instalación y lanzamiento de instancias Vanilla y Fabric. Selección de Java por perfil, detección de Java local y de runtimes del launcher oficial, y prueba de memoria y argumentos.
- Mods, resourcepacks y shaders desde Modrinth, con búsqueda, versiones, dependencias, activación y actualización. La tienda de modpacks permite escoger la versión exacta antes de instalar.
- Gestión de cuenta y estudio de skin originales: PNG, modelo, capas, vista previa e historial local. La aplicación de skins está conectada; su validación manual con una cuenta real sigue pendiente.
- Servidores guardados, detección de ZeroTier y revisión de mods antes de jugar. La sincronización requiere el servicio `icaro-sync-host.exe` en el PC del anfitrión y una instancia cliente de Ícaro preparada para su servidor; no obtiene el inventario automáticamente de Minecraft.
- Instancias con carpetas legibles, archivos de Minecraft compartidos, exportación ZIP, consola, capturas y acciones de recuperación.
- Grabados preparados sin pérdida: se conservan sus píxeles y se reduce el tamaño del paquete.

## Pendientes de esta etapa

Quilt, Forge y NeoForge todavía no cuentan con instalación y lanzamiento completos. CurseForge, importación de modpacks locales y varias cuentas persistentes siguen pendientes. La sincronización necesita validación completa entre dos equipos autorizados por ZeroTier.

Esta entrega publica paquetes de Windows. El recorrido completo y la distribución de Linux siguen pendientes de validar. Los ejecutables de Ícaro aún no tienen firma digital.

Las pruebas automáticas y las comprobaciones locales de instalación, actualización silenciosa y retorno nativo cubren esos componentes; el acceso completo con el paquete corregido, las skins y las pruebas entre equipos necesitan comprobación manual. El [roadmap](../../README.md#roadmap) conserva esos pendientes.

## Para jugar

Se necesita una cuenta con acceso a Minecraft Java y una instalación de Java compatible con la instancia. La autorización ocurre en Microsoft; Ícaro recuerda la sesión mediante el almacén de credenciales del sistema. Para el servicio del anfitrión, consulta la [guía de sincronización](../sincronizacion-servidores.md).
